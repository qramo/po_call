話すボタンの位置

通話テスト

おうむ返しボットが動いているときだけ使えます。話すと、あなたの声が返ってきます。

効果音

スライダーを離すと、試しに「ガッ」と鳴ります。効果音を消したいときは、音量を 0% にしてください。

通信の診断

うまくつながらないときに使います。ボタンを押すと、設定が閉じて、メイン画面の下に診断が出ます。部屋に入ったまま、相手ごとの接続の状態を見られます。画面を撮って送ると、原因を調べやすくなります。

切り替えると、ページを読み込み直します。部屋のみんなが同じ設定である必要はありません。

ぽちっと通話 α版

このアプリは？

ボタンを押している間だけ話せる、トランシーバー風の音声通話アプリです。アカウント登録やログインは要りません。同じ部屋に入った人どうしで話せます。α版のため、予告なく仕様が変わったり、動作が不安定だったりすることがあります。

使い方

  • ハンドルネームを決めて、「新しい部屋を作る」か、一覧の部屋をタップして入ります。
  • 入室後は、大きなボタンを押している間だけ話せます（PCではスペースキーも使えます）。
  • 「招待URLをコピー」で友達にURLを送ると、同じ部屋に入れます。
  • 誰かが話している間は話せません（話中）。同時に押すと混線して、どちらも送信が切れます。
  • 部屋の中のQRボタンを押すと、無線機が裏返って、招待URLのQRコードが出ます。友達がスマホで読み取ると、同じ部屋に入れます。「もどる」で表に戻ります。
  • 部屋の中では、「話題タグ」をつけられます（30文字まで）。誰でも変えられ、付けた人の名前が添えられます。部屋の一覧にも表示されます。
  • 相手が見つからない、声が届かなくなったときは、「再接続」を押すと、部屋に入ったまま接続をやり直します。自動でやり直したいときは、設定の「自動で再接続する」をオンにします（標準はオフ）。iPhone は、画面を消したりほかのアプリに切り替えたりすると通話が止まるので、アプリに戻ってください。
  • 部屋の一覧の人数と、実際につながっている人数が、10秒以上合わないときは、画面に知らせが出ます。自動で再接続をオンにしていれば、25秒たっても合わないときに、つなぎ直します。相手が、ブラウザを突然閉じたときは、一覧の表示が、20秒ほど残ります。それでも合わないときは、「再接続」を押してください。
  • 1人で待っているとき、約10分ごとに、画面を自動で読み込み直します（部屋には、そのまま戻ります）。待っている間に、つながりにくくなるのを防ぐためです。話している間や、誰かとつながっている間は、読み込み直しません。
  • 1つの部屋は、8人までです。満員の部屋には、入れません。同時に入って超えたときは、あとから入った人が、自動で退出します。

プライバシー

誰に何が見えるか

  • ハンドルネーム・今いる部屋・話し中かどうかは、このアプリを同時に開いている全員に見えます（部屋一覧のため）。本名や個人が特定できる名前は使わないでください。
  • 話題タグと、付けた人のハンドルネームも、一覧で全員に見えます。個人情報は書かないでください。
  • 部屋は公開です。部屋のハッシュ値は一覧に出るので、誰でもタップして入れます。秘密の話をする用途には向いていません。
  • 同じ部屋の人には、あなたのIPアドレスが見えることがあります。通話が端末どうしの直接通信（P2P）で行われるためです。
  • 同じ部屋の誰かが、自分の端末で通話を録音する可能性はあります。このアプリには防ぐ仕組みはありません。

音声について

  • 音声は、通常、端末どうしで直接送られます。直接つながれない場合だけ、CloudflareのTURNサーバーを中継して送られます。通信はWebRTCの標準の暗号化がかかるため、中継サーバーが内容を聞くことはできません。TURNが使えないときは、端末どうしの直接通信に切り替わります。
  • このアプリの運営側は、音声を受け取らず、録音も保存もしません（そもそも運営側のサーバーに届きません）。
  • おうむ返しの部屋では、ボット（このアプリの運営側が動かしている端末のページ）が、あなたの声を、返事を返すために、そのページのメモリの中だけで、一時的に録音します。返事を返したあとは使わず、ファイルへの保存も、外部への送信も、文字への書き起こしも、しません。ボットは、話した内容を覚えていません。
  • VOX（声で自動送信）をオンにすると、声を検出するために端末の中でマイクの音量を監視します。この監視用の音は送信も保存もされず、声を検出したときだけ送信が始まります。同じ理由で、マイクが使える状態の間は、画面のレベル表示のためにも端末の中で音量を測っています。ホーム画面の「マイクテスト」は、入力レベルとメーターの確認のためにマイクを使いますが、音声は送信も保存もされません。VOX自体は、ページを開き直すとオフに戻ります（しきい値の設定だけ、端末に保存されます）。
  • マイクは、部屋に入るときに許可を求めます（許可しなかった場合は、話すボタンを押したときにもう一度確認します）。許可後は、部屋に入っている間マイクを確保しますが、ボタンを押していない間は音声を送りません（ブラウザのマイク使用中の表示は出たままになります）。部屋を退出すると、マイクを解放します。

あなたの端末に保存されるもの

  • 通信の記録: 標準では、端末に保存しません（診断画面のために、画面の中だけで一時的に持ち、読み込み直すと消えます）。設定で「通信の記録を、この端末に残す」をオンにしたときだけ、直近の出来事（時刻、相手のハンドルネーム、通信の状態、中継サーバーのアドレスなど）を、最大300行、localStorage（キー名 pochitalk_log_v1）に保存します。外部へは送信しません。オフにすると消えます。記録を残しているあいだは、あなたのハンドルネームの前に 💾 が付き、同じ部屋の人や一覧にも見えます。
  • ハンドルネーム: ブラウザの localStorage（キー名 pochitalk_ptt_name）に保存されます。次回開いたときに入力済みになります。この端末のブラウザの中だけにあり、運営側には送られません。ブラウザのサイトデータを消すと削除されます。
  • URLの「?r=…」: 今いる部屋のハッシュ値がアドレスに入ります。ブラウザの履歴に残ることがあります。
  • 新しい部屋の音: 設定で「新しい部屋ができたら、音で知らせる」をオンにしたときだけ、その旨を localStorage（キー名 pochitalk_notify_room）に保存します。このアプリを開いている間だけ、新しい部屋ができたときに、この端末の中で、音を鳴らします。画面の知らせや、ブラウザの通知は出しません。運営側のサーバーから何かが送られることもありません。
  • 規約に同意した記録: 初回案内で、利用上の注意に同意したとき、その版の番号（日付）を、localStorage（キー名 pochitalk_terms）に保存します。この端末のブラウザの中だけに残り、外部へは送信しません。規約を大きく変えたときだけ、もう一度、同意をお願いします。
  • 初回案内の表示設定: 初回の案内で「次回も表示する」をオフにしたときだけ、その旨を localStorage（キー名 pochitalk_welcome）に保存します。この端末のブラウザの中だけにあり、運営側には送られません。
  • 話すボタンの位置: 左または右にしたときだけ、その旨を localStorage（キー名 pochitalk_ptt_pos）に保存します。この端末のブラウザの中だけにあり、運営側には送られません。
  • 左手用の設定: ONにしたときだけ、その旨を localStorage（キー名 pochitalk_lefty）に保存します。この端末のブラウザの中だけにあり、運営側には送られません。
  • 効果音の音量: 0〜150%の数字を、同じく localStorage（キー名 pochitalk_sfx_vol）に保存します。この端末のブラウザの中だけにあり、運営側には送られません。
  • 入力レベル: マイクの増幅（0〜30dB）の数字を、同じく localStorage（キー名 pochitalk_input_db）に保存します。この端末のブラウザの中だけにあり、運営側には送られません。
  • VOXのしきい値: 1〜10の数字を、同じく localStorage（キー名 pochitalk_vox_thr）に保存します。この端末のブラウザの中だけにあり、運営側には送られません。
  • Cookie、ログイン情報、メールアドレス、位置情報、連絡先などは、保存も取得もしません。
  • アクセス解析や広告の仕組みは入れていません。

サーバー側に保存されるもの

  • おうむ返しボットは、動かしている端末のページに、直近60行までの出来事の記録（参加した人のIDの先頭5文字、退出した人のハンドルネーム、エラー、読み込み直しの理由）を表示します。ページの中だけにあり、読み込み直すと消えます。声の内容は、記録に含みません。
  • このアプリの運営側には、データベースや保存領域がなく、ユーザーの名前・部屋・音声・通話履歴を保存していません。
  • ただし、ページを配信している GitHub Pages には、一般的なアクセス情報（IPアドレスなど）が、同社の方針に沿って記録されることがあります。

外部のサービスについて

  • ライブラリ: 通話用のライブラリ（Trystero）・QRコードを作るライブラリ・在室の知らせに署名するライブラリは、このページと同じ potalk.app から配信します（外部の配信元は使いません）。QRは端末の中で作られ、招待URLは外に送られません。
  • TURN の資格情報: ぽっと通話（potalk.app）と同じ Cloudflare Worker から、短い期限の資格情報を受け取ります。この Worker は資格情報を渡すだけで、音声・接続情報・在室の知らせは通りません。
  • Nostr の公開リレー: 通話相手を見つけるための接続情報のやり取りと、部屋の一覧のための在室の知らせ（部屋のハッシュ、ハンドルネーム、話題タグ、話しているか）の送受信に使います。内容は暗号化されますが、接続元IPなどのアクセス情報はリレーの運営者に見える可能性があります。
  • STUN / TURNサーバー（Cloudflare・Google）: 端末どうしが直接つながるための、公開されたアドレスの確認に使います。IPアドレスがこれらに送られます。
  • これらは運営側が管理していない外部のサービスです。

ご注意

  • 回線やNATの種類によっては、相手とつながらないことがあります。
  • 他人への迷惑行為や、他人の会話の録音・公開はしないでください。
