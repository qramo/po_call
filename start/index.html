テーブルは、いくつあってもかまいません。空いている席に座るか、新しいテーブルをとるか。ポットが温かければ、誰かがいる合図。名前も登録もいりません。カップを置いて席を立てば、それでおしまい。

いつもポットが温かいテーブル

ふたつだけ、いつも用意してあるテーブルです。人がいれば「温かい」と出ます。いなくても、入って待っていれば次に来た人と話せます。

🫖 はじめましての席 確認中… 入って待つと、次に来た人と話せます → ⛰️ 声を試す席（やまびこ） 確認中… 5 秒後に自分の声が返ってきます。マイクの確認にどうぞ →

一つのテーブルに座れるのは 8 人まで。いっぱいなら、隣に新しいテーブルをとれます。

はじめかた

  1. 開くブラウザで potalk.app を開きます。アプリのインストールも、登録もいりません。
  2. 名前を決める名前と絵文字を決めます。本名でなくて大丈夫。ブラウザが覚えていて、次回も同じです。
  3. 席につく「通話中の部屋」から選んで入るか、部屋の名前をつけて新しいテーブルをとります。マイクの許可を一度だけ聞かれます。

友だちを呼ぶときは、招待リンクか QR コードを送ります。リンクがそのまま席への入口です。

テーブルでできること

  • 🎙️
    声だけで話す顔は出ません。ミュートはいつでも。
  • 💬
    ひとことと相づち短い文字と、8 種類の絵文字のリアクション。
  • 🏷️
    話題タグいま何の話をしているか、席に札を立てられます。
  • 📣
    主のお茶会（配信部屋）主の声だけが流れる席。聞くだけの人も座れます。おたよりも送れます。
  • 🎵
    BGM と小窓静かな BGM を流したり、小さな窓に畳んでほかの画面を見ながら。
  • 🌗
    昼と夜時刻で色が変わります。昼はミルクティー、夜は紺。

安心して座れる理由

中身は公開していますプログラムはすべて GitHub で読めます。隠している仕組みはありません。
声はお互いのブラウザどうし声はお互いのブラウザどうしを直接つなぎます。途中で保存されることはありません。
席を立てば終わり部屋は人がいなくなると消えます。録音の機能はありません。
登録なし・無料メールアドレスも電話番号もお伺いしません。

実験版です。予告なく変わることがあります。合わない人の声は「無視」で自分にだけ聞こえなくできます。詳しくは使い方としくみへ。
