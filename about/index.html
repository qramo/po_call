運営について

ぽっと通話は、個人が作って公開している実験版のサービスです。運営組織はなく、個別のサポートもできません。そのぶん、しくみを公開し、質問や不具合は掲示板でみんなで助け合う形にしています。

制作者

♨️🦈 qramo（クラモ）on POPOPO。配信アプリ POPOPO にインスパイアされて作り、POPOPO の枠で開発の様子を配信しています。開発は AI（Claude Code）と一緒に進めています。

ご意見・質問・不具合報告

ぽっと通話 ご意見・質問ばんへどうぞ。アカウント不要・匿名で書けます。不具合は「いつ／どの端末とブラウザ／どうなったか」があると助かります。

掲示板は外部サービス（zawazawa）です。書いた内容はそのサービス側に公開されます。

プライバシー

運営はサーバを持たないので、運営の手元に利用者のデータは集まりません。それでも「どこに何が残るか」は書いておきます。

どこに何が補足
あなたのブラウザ（localStorage）名前・絵文字・育ち具合・設定（音量、BGM、通知の音、昼夜）・配信部屋の主の鍵・無視の説明を読んだかどうかブラウザごとに別。消すと名前や育ちは最初からになります
同じ部屋の相手のブラウザ名前・絵文字・ミュート中か・経路の印・育ち具合・ひとこと・相づち・話題タグ・おたより（主にだけ）通話中だけ。保存されません
ロビー（ページを開いている人どうしのメッシュ）通話中の部屋の名前・人数・続いている時間・話題タグ・参加者の名前と絵文字非公開の部屋はありません。人がいる部屋はかならず一覧に出ます
公開の Nostr リレー（第三者）相手探しの合図（暗号化）と、在室の合図（部屋名のハッシュと絵文字だけ）部屋名や人の名前は載せません
Cloudflare（第三者）中継を通る暗号化された音声（中身は読めない）と、中継の鍵の発行ふだんの声の通り道。しくみ参照
Cloudflare Web Analyticsアクセス数だけCookie 不使用・個人を特定しません。集計は README で公開
  • 声は録音されず、保存もされません。過去の会話は残りません。
  • 相手にあなたの IP アドレスはふだん見えません。中継が使えず直接つながったときだけ見えます（参加者の行に ↔ が出ます）。
  • メールアドレスも電話番号もお伺いしません。

利用のお願い

  • 実験版です。切断や不具合が起きることがあります。利用で生じた損害は自己責任でお願いします。
  • 一般的なモラルを守ってお使いください。ほかの人を不快にする言動、迷惑行為、違法な行為はしないでください。
  • 合わない相手がいたら「無視」で自分の画面からその人の声と文字を消せます。相手には伝わりません。それでも困るときは席を立ってください。
  • 非公開の部屋はありません。人がいる部屋はかならず一覧に出るので、そのつもりでお使いください。
  • 年齢や人によって向かない話題もあります。周りの人に配慮してください。

正式な利用ガイドラインは作成中です。それまでは上のお願いが指針です。
