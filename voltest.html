🔊 音量テスト

iPhone で「どの方法なら音量が変わるか」を確かめるページです。
上から順に押して、聞こえ方がどうなったかを教えてください。イヤホンでも本体スピーカーでも構いません。

① 音を出す

→ ポーという音が鳴りますか？（鳴らなければここで止めて連絡してください）

② 素の .volume を 20% にする

→ 小さくなりましたか？（変わらなければ、この方法は iPhone で効かない＝原因確定）

③ 素の .volume を 0 にする

→ 無音になりましたか？

④ Web Audio（GainNode）経由に切り替えて 20%

→ 音は鳴っていますか？ 鳴っているとして小さくなりましたか？
（ここで無音なら、iPhone は「muted の要素＋Web Audio」では鳴らせない＝別の手が要る）

⑤ GainNode を 0 にする

→ 無音になりましたか？

⑥ 100% に戻す（muted を外して素の再生へ）

→ 元の大きさで鳴りますか？（ここが戻らないのが一番まずい壊れ方です）
