部屋をタップするとそのまま入室します。通話中は確認のうえ移動します。
新しい部屋の音は、このタブを開いている間だけ鳴ります（スマホは裏に回ると鳴りません）。

このサイトはアクセス測定に Cloudflare Web Analytics を利用しています（Cookie不使用・個人を特定する情報は取得しません）。

🫖 これはなに？

同じ部屋名を開いた人どうしが、そのまま音声でおしゃべりできる実験的なミニ通話Webアプリです。アプリのインストールはいらず、ブラウザだけで使えます。配信アプリ POPOPO にインスパイアされて作りました。

⚠️ 実験中です。ご利用は自己責任で！

つかいかた

まず（共通）

  • 名前とアバター（絵文字）を決める（ブラウザに保存され、次回も引き継ぎます）

部屋を作る

  1. 部屋名を入れて「参加する」→ マイクを許可
  2. 同じ部屋名・共有リンク・QRコードを相手に渡す

部屋に入る

  • 「通話中の部屋」から選んでタップ（共有リンク／QRからも入れます）→ マイクを許可

💡 部屋名はURLの一部（末尾の #◯◯）。共有リンク＝その部屋のURLなので、開けば同じ部屋に入れます。

📢 配信部屋

「あなたが話し、ほかの人は聞く」形の部屋です。部屋名の下で 📣 配信部屋にする を選んで参加すると作れます（既定は 🏠 雑談部屋＝全員で話せる、これまでどおりの部屋）。共有リンクは 1種類だけ（配信者用の秘密のリンクはありません）。

  • 聞き役で入った人は マイクを使いません（許可を求められません）
  • 誰かに話してもらいたくなったら、参加者リストの 🎙 を押すと その人も話せます（もう一度押すと戻ります）
  • 許された人の画面には「マイクを使う」が出ます。押すまでマイクは入りません

💡 配信者かどうかは URL ではなく 部屋を作った端末で決まります（鍵をブラウザに保存しています）。別の端末やデータを消したあとでは、同じ部屋の配信者に戻れません。

💡 「話してよい人」の一覧は配信者が署名して配っており、各自のブラウザが確かめてから音を鳴らします。名乗るだけでは配信者になれません。

📮 おたより（配信部屋）

ラジオの投稿コーナーです。配信者がお題を出して募集し、聞いている人が書いて送り、配信者が選んだお便りだけが部屋に出ます。

  1. 配信者：📮 おたよりタブでお題を書いて「募集する」（例：最近食べて美味しかったもの）
  2. 聞いている人：同じタブにお題が出るので、お便りを書いて「送る」（送り直せます。1人1通）
  3. 配信者：集まったお便りから選んで「公開」。全員の画面に出ます

💡 送ったお便りは配信者にしか届きません（ほかの人の画面には出ません）。公開されたものだけが部屋に出ます。

💡 公開されるのはいつも1通だけ。次を公開すると入れ替わります。読み終えたら「公開をやめる」で下げられます。

できること
  • ☎️ ロビー：いま通話中の部屋が一覧で見える（続いている時間も）
  • 👥 参加者：名前・絵文字が出て、話している人の絵文字が跳ねる／ミュートも表示
  • 🌱 育てる：使うほどあなたの絵文字が成長（🌱→🌿→🌷or🌻→❓）
  • 🔔 音：入室・退出や新しい部屋を音で知らせる（それぞれオン/オフ。新しい部屋の音はタブを開いている間だけ）
  • 👥 人数：ふつうの部屋は 8人、📣 配信部屋は 15人まで（全員が全員に繋がる仕組みなので、多いと音が途切れます）
いつもある部屋
  • 🫖 POへようこそ：はじめての人向けの案内が流れています。一人で入っても声が聞こえます
  • ⛰️ やまびこ部屋：接続テスト用。話すと自分の声が5秒後に返ってきます（ちゃんと繋がっているかの確認に）。イヤホン推奨（スピーカーだと自分の声が繰り返すことがあります）

💡 これらは運営PCで動いている部屋なので、動いていない時間帯は一覧に出ないことがあります。

しくみ・プライバシー
  • 通話はブラウザどうしを直接つなぐ仕組み（WebRTC）です。運営はサーバを持たず（サーバレス）、通話の中身が運営の手元を通ることはありません
  • 音声は暗号化してやり取り（サーバに録音・保存されません）。ふだんは Cloudflare の中継を通すので、相手にあなたの IP アドレスは見えません（中継先も暗号化された中身は聞けません）
  • 中継を通せなかったときは、そのまま相手と直接つなぎます。通話はふつうに使えますが、そのときだけ相手にあなたの IP アドレスが見えます。いまどちらかは、参加者リストの右端の印（☁️＝中継／↔＝直接）で一人ずつ分かります
  • 非公開の部屋は作れません。通話中の部屋はかならずロビーに出ます（部屋名・参加者・どのくらい続いているか・話しているかどうか）。隠す設定はどこにもない、というつくりです
  • 通話中は「その部屋が今ライブか」を外部（ブログのバナー等）が表示できるよう、在室情報を公開Nostrリレーに送っています。部屋名そのものは送らず、伏せた値（ハッシュ）にしているので、部屋名を知らない人に一覧で覗かれることはありません（運営サーバは介しません）
  • アクセス数の測定に Cloudflare Web Analytics を使用（Cookie不使用・個人は特定しません）
注意（実験版）
  • 実験中のため、切断や不具合が起きることがあります
  • マイクの許可が必要です。Safari / Chrome で開いてください（アプリ内ブラウザは不可）
  • iPhoneでは「音声を有効化」ボタンが出ることがあります
  • 快適なのは 4〜6人 くらいまで（全員が全員につながる方式のため）
  • 回線によっては稀につながらないことがあります
  • 過去の会話は残りません（録音保存なし）
  • ブラウザは別々に扱われます：スマホとPCは別、PCでもSafari/Chromeなど別ソフトは別、同じChromeでもプロファイルが違えば別ブラウザ扱い（名前や成長は引き継がれません）。ホーム画面に追加したものも別扱いです（追加すると名前と絵文字は選び直しから、育てるも最初からになります）
  • 利用で生じた損害は自己責任で。一般的なモラルを守ってお使いください。（利用ガイドライン作成中）
